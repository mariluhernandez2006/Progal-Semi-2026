PROYECTO ACADÉMICO - VISUAL BASIC 2019 - WINDOWS FORMS

1. Abre AcademicaVB2019.sln en Visual Studio 2019.
2. Instala la carga de trabajo Desarrollo de escritorio con .NET y .NET Framework 4.8.
3. Debes tener SQL Server LocalDB (MSSQLLocalDB) instalado.
4. Ejecuta BaseDatos.sql en SQL Server Management Studio conectado a (LocalDB)\MSSQLLocalDB.
5. Si tu servidor es otro, cambia Data Source en App.config.
6. Ejecuta con F5. Usuario: USTR025826, clave: pastel#123.

El diseño se genera por código en las clases de formularios: NO necesitas arrastrar controles.
El código del proyecto de clase C# se convirtió a Visual Basic: conexión, DataSet, alumnos y materias.
Se añadieron login y gestión de usuarios solicitados en el examen.

AVISO: las contraseñas se guardan en texto plano para reproducir la estructura solicitada en el parcial. No usar en producción: en sistemas reales se deben almacenar hashes seguros.
No se ha probado este proyecto dentro de Visual Studio ni con una instancia SQL Server real.
